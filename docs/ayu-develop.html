Purpose and scope

Cross-system reference and framework-specific SMA examples plus a local CSV extraction utility; this repository delegates simulation to installed frameworks and bundles no current sample data.

Strengths and limits

Strengths

  • Concrete example code shows the host API used for one trading rule and CSV preparation. run_benchmark (L90) / run_sma_crossover_strategy (L119) / extract_data (L43)

Limitations

  • Cross-system SMA semantics are not identical: Backtesting.py uses above/below regime checks, Backtrader uses crossover events and trade_on_close settings differ. SMACrossStrategy (L39) / SMACrossoverStrategy (L22) / run_benchmark (L90)
  • Backtrader loader silently synthesizes missing OHLC/volume fields; this can invalidate benchmark data quality. prepare_data (L92)
  • Current sample CSV and obsolete Blankly guides have been removed; existing README/docs edits are preserved. Historical single-run timings and prose rankings are not controlled comparative evidence. README.md / docs/validation.md

Validation scope

The linked validation and command records preserve actual historical runs and user-authorized exclusions. This source/document review does not rerun application tests, establish live trading readiness or rank benchmark performance. Current data, credential and runtime prerequisites remain material.
